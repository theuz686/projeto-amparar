# 🌿 Projeto Amparar  
**Plataforma social de apoio a mulheres em situação de vulnerabilidade**

O **Projeto Amparar** é um sistema criado com o objetivo de auxiliar o cadastro, organização e acompanhamento de mulheres, famílias e acolhidas em situação de vulnerabilidade social.  

A plataforma permite que a equipe administrativa gerencie informações de forma eficaz, proporcionando mais organização, transparência e agilidade às ações do projeto.

---

## 🚀 Funcionalidades Principais

### 🌐 **Páginas Institucionais**
- **Início** — apresentação geral do projeto  
- **Sobre Nós** — missão, visão e história do projeto  
- **Apoie** — instruções para quem deseja contribuir  
- **Loja** — seção comercial para arrecadação ou produtos  
- **Galeria** — fotos e registros das ações do projeto  

---

## 📝 **Formulários do Sistema**
- Cadastro de Amparadas  
- Cadastro de Voluntárias  
- Cadastro de Acolhidas  
- Página unificada de cadastros (atalhos para todas as opções)

---

## 🛠 **Área Administrativa**
Acesso restrito para equipe autorizada, contendo:

- Listagem de cadastros  
- Edição de dados  
- Exclusão de registros  
- ✔️ *Login Administrativo ativado*
